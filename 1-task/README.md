Реализуйте функцию `add`:

-   функция принимает 2 аргумента, оба аргумента - числа типа `number`. Любой другой тип не принимается. Если пользователь передаёт не числа, `NaN` или `Infinity`, то нужно выбросить ошибку [throw](https://developer.mozilla.org/ru/docs/Web/JavaScript/Reference/Statements/throw) с описанием `WrongType`;
-   функция должна возвращать сумму аргументов;
-   функция должна экспортироваться: `export function functionName() { ... }`.
